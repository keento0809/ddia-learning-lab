# セキュリティ関連規約(ADR-010/ADR-011)

- 外部リソース(画像・フォント・スクリプト等)への新規依存を追加するタスクでは、
  受入基準に「CSPの該当ディレクティブが新規ホストを許可していることの確認」
  を含めること。CSP更新を伴わずに外部ホスト依存を追加すると、本番で当該
  リソースがブロックされる(例: Googleプロフィール画像がimg-src未許可で
  ブロックされた実例。詳細: STATUS.md 2026-08-19)。
- CSP(`tests/unit/security/csp.test.ts`等)の変更を伴うタスクでは、既存の
  関連セキュリティ記録(`docs/security/findings.md`、`tests/security/`配下)
  との整合を確認するステップを受入基準に含めること。過去の検証記録に
  誤り(`<style>`要素とstyle属性の混同)があり、それが見過ごされたまま
  別タスクに引き継がれた実例がある(詳細: STATUS.md 2026-08-19)。
