# 信頼できないクロック

分散システムでは、イベントの前後関係を判断したり、キャッシュの有効期限を
管理したり、タイムアウトを計測したりと、あらゆる場面で「時刻」や
「経過時間」の情報を使います。ところが、複数のマシンにまたがってこれらの
情報を扱おうとすると、単一マシン上のプログラムでは意識する必要のなかった
落とし穴に出会います。

## 2種類のクロック

多くのOSは、用途の異なる2種類のクロックを提供しています。

- <Term slug="wall-clock-time">壁時計時刻(wall-clock time)</Term>: 「現在は2026年7月26日 10:00である」のような
  実世界のカレンダー時刻。NTP(Network Time Protocol)などで他のサーバーと
  定期的に同期される
- <Term slug="monotonic-clock">単調クロック</Term>: ある基準点からの経過時間を
  計測するためのクロック。同期補正やユーザーによる時刻変更の影響を受けず、
  常に前進し続けることが保証される

「2つの処理の間に何ミリ秒かかったか」を知りたいだけなら、単調クロックを
使うべきです。壁時計時刻は同期補正によって前後に飛ぶことがあるため、
経過時間の計測に使うと、補正のタイミング次第で負の経過時間や異常に大きな
経過時間を観測してしまうことがあります。

```
壁時計時刻を使った経過時間計測(危険な例)
  t1 = 壁時計時刻を取得         例: 10:00:00.000
  ... 処理 ...
  (この間にNTP補正で時計が3秒戻る)
  t2 = 壁時計時刻を取得         例: 10:00:02.700 (本来は10:00:05.700のはず)
  経過時間 = t2 - t1 = 2.7秒    → 実際より短く見える(最悪、負の値にもなり得る)

単調クロックを使った経過時間計測(安全な例)
  t1 = 単調クロックを取得       例: 120.000秒(起動からの経過)
  ... 処理 ...
  t2 = 単調クロックを取得       例: 122.700秒
  経過時間 = t2 - t1 = 2.700秒  → 補正の影響を受けない
```

<Callout type="tip">
  タイムアウトの計測やリトライ間隔の計算など「経過時間」を扱う処理は、
  実装言語が提供する単調クロックのAPIを使うのが基本です。壁時計時刻は
  「いつ」を表示・記録する用途に限定して使い分けます。
</Callout>

## クロックドリフトという避けられない誤差

<Term slug="clock-drift">クロックドリフト</Term>
とは、各マシンに搭載された水晶発振器の個体差や、温度・経年劣化などの
環境要因によって、実時間に対して時計の進み方にわずかなずれが生じる現象
です。1台のマシンだけを見ても、時計は常にわずかに速く、あるいは遅く
進み続けており、この誤差はNTPで定期的に補正されるまでの間、時間の
経過とともに蓄積します。

ドリフトの大きさはハードウェアや環境により異なりますが、無視できるほど
小さいとは限らず、補正の間隔が長い環境や、補正自体が何らかの理由で
失敗し続けている環境では、無視できない秒単位のずれに育つこともあります。

## 「別々のマシンの時刻」を比較する怖さ

「ノードAが記録したタイムスタンプ」と「ノードBが記録したタイムスタンプ」を
単純に大小比較して、どちらのイベントが先に起きたかを判断したくなる場面は
よくあります。しかし、AとBのクロックにドリフトがある以上、この比較には
誤差が乗っています。

- ドリフトの上限が事前にわかっているなら、比較の際にその上限をマージンとして
  見込む(タイムスタンプの差がドリフト上限より小さい場合は前後関係を
  確定させない)
- 前後関係の確定が必須な処理(排他制御の判定など)では、壁時計の比較だけに
  頼らず、後続モジュールで扱う論理クロックや合意アルゴリズムのような
  別の仕組みを検討する

<Callout type="warn">
  「NTPで同期しているから複数ノードの時計はほぼ一致している」という前提は、
  平常時には概ね成り立ちますが、ネットワーク分断でNTPサーバーへ到達できない
  期間や、NTPクライアントの設定ミスがあった場合には成り立ちません。
  クロックの信頼性は「常に成り立つ保証」ではなく「多くの場合に成り立つ
  期待値」として扱うのが安全です。
</Callout>

本モジュールの演習では、この「クロックドリフトの上限」を考慮に入れて
タイムアウト値を安全側に補正する計算を実装します。
